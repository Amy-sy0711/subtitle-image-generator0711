# 图片字幕生成器

一个纯前端、零依赖的单文件网页工具：给图片底部批量叠加多行字幕并导出 PNG。直接用浏览器双击打开 `index.html` 即可使用，无需安装、无需联网、无需后端。

## 功能要点

- 多行字幕：文本域一行一条，自动按行数生成等高字幕条
- 统一背景条：只裁切、压暗一次底部条带，再复用到每一行，各行背景完全一致
- 行间分隔线与文字描边/填色可自定义（字幕高度、字号、字体、字色、轮廓色）
- 字体选择：可搜索的中文/英文候选字体清单，也支持手动输入自定义字体名
- 预览与导出共用同一 Canvas，导出尺寸严格等于原图像素，文件名自动追加 `_字幕.png`

## 说明

字体依赖访客系统已安装的字体，缺失时按内置回退栈逐级降级（不加载任何在线 Web 字体），因此不同机器上字形可能不同。

部署：把 `index.html` 放到任意静态托管（GitHub Pages、对象存储、Nginx 等）根目录即可，无需构建。
